# Black Lodge

159/2021 - Mateja Ivanovic

This project is based on the Black Lodge from Twin Peaks.
Features a Physically Based Model with lighting, Directional and Point Shadow Maps  
and Physically Based Bloom

## Controls

W -> Move forward  
A -> Move left  
S -> Move backward  
D -> Move right  
Scroll whell -> Zoom  
ESC -> Exit game  
F1 -> Capture mouse  
F2 -> Toggle GUI  
E -> Start the event chain

## Features

[X] Model with lighting
